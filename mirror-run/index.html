Mirror Run

One thumb steers both runners. Drag anywhere: the day runner follows your finger and the night runner moves as its reflection.

Each side gets different walls. Find the one spot that gets both through. When an amber line crosses, the mirror flips to parallel and both move the same way. Then it flips back.
