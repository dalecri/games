Thread

You have one thread, tied to a pin. Drag from the end of the thread across other pins to wrap it around them. The thread can never cross itself.

Bring it back to any pin it already touches and the loop closes. Everything inside is caught, and the beads give you more thread. Closed loops are permanent, so every loop reshapes the board.

beads: 3 or more of one colour in a loop scores double gems: worth three beads spools: +250 thread burrs: they fray thread, so leave them outside
