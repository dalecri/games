# Quick Play Games

Fifteen tiny browser games in one repo. Every game is a single self-contained HTML file (no build, no dependencies), shelved in its own folder as `index.html` so each one gets a clean URL:

`heycristobal.com/Quick-Play-Games/<folder>/`

| Game | Play | About |
|---|---|---|
| Lasso.io | [lassoio/](lassoio/) | Circle rivals and cut ropes in a western arena |
| Afterimage | [afterimage/](afterimage/) | Trace a fading route from memory |
| Fence | [fence/](fence/) | Claim pasture before the slime spreads |

| Glide | [glide-game/](glide-game/) | Ride the air as a paper airplane |

## Adding a game

1. Create a folder named for the game and put the game in it as `index.html`.
2. Add a card for it in the root `index.html` gallery.
3. Add a row to the table above.
